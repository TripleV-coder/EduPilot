# 16. Lexique

| Mot | Sens dans EduPilot |
|---|---|
| **Absence justifiée** | absence à une évaluation, avec motif visé par le directeur des études : la note est retirée du calcul |
| **Absence non justifiée** | absence à une évaluation sans justificatif : la note vaut 0 (modifiable si l'élève recompose avant le conseil) |
| **Arrondi** | un seul, à la fin, au centième, demi vers le haut (12,345 devient 12,35) |
| **Barème** | note maximale d'une évaluation (sur 10, sur 20, sur 40…). Toute note est ramenée sur 20 |
| **Coefficient** | poids d'une matière dans la moyenne générale, réglé pour chaque classe |
| **Composition** | évaluation de fin de période, comptée comme un devoir |
| **Conseil de classe** | réunion de fin de période. Sa validation fige les notes et les coefficients de la période |
| **Cycle** | Primaire, Collège ou Lycée |
| **Devoir** | devoir surveillé, devoir de niveau, composition ou examen blanc : compte seul dans la moyenne de la matière |
| **Dispense** | élève dispensé d'une épreuve (EPS médicale…) : traité comme une absence justifiée |
| **DT** | Diplôme de Technicien, équivalent du BAC (filières EA, MIA, HR) |
| **Effectif** | élèves inscrits et actifs dans la classe ; un abandon n'est plus compté |
| **Ex aequo** | même moyenne affichée, donc même rang ; le rang suivant est sauté |
| **FCFA** | franc CFA : montants toujours entiers, sans centimes |
| **Interrogation** | interrogation écrite ou orale, exposé, travaux pratiques : forme la moyenne des interrogations (MI) |
| **MI** | moyenne des interrogations de la période, pour une matière |
| **Moyenne annuelle** | (T1 + T2 + T3) ÷ 3 en trimestres, (S1 + S2) ÷ 2 en semestres |
| **Moyenne de matière** | (MI + D1 + D2) ÷ 3, soit (MI + somme des devoirs) ÷ (1 + nombre de devoirs) |
| **Moyenne générale** | moyennes des matières pondérées par leurs coefficients |
| **Moyenne provisoire** | moyenne calculée en cours d'année sur les seules périodes déjà évaluées |
| **NC** | « non classé ». Pour une note : pas encore tranchée par le professeur, retirée du calcul sans rien bloquer. Pour une matière : aucun devoir compté alors que des devoirs étaient prévus |
| **Période** | trimestre ou semestre |
| **Rachat** | passage accordé sous le seuil, uniquement après conseil de classe (option de l'école) |
| **Rang de classe** | place de l'élève dans sa classe, selon la moyenne de la période |
| **Rang de promotion** | place parmi tous les élèves du même niveau (option) |
| **Réclamation** | demande de correction d'une note après le conseil : rendez-vous, examen de la copie en présentiel, correction saisie par l'enseignant, approuvée par le directeur des études |
| **Série** | voie du second cycle (A1, A2, B, C, D, E, F1 à F4, G1 à G3, EA, MIA, HR) |
| **Seuil de passage** | moyenne annuelle minimale pour passer, 10 par défaut |
| ✅ / 🔧 | règle en place / règle décidée, en cours de finalisation |
